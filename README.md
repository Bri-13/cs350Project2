How to compile:
1. Install Docker or the VM, xv6, and qemu.
2. Run Docker or the VM and clone this repo.
3. Open the folder cs350Project2 in a terminal and navigate (cd) to xv6-kernel-threads.
4. Type in "make qemu-nox" and press enter.


How to run:
1. For part 1:
    - To run the first test, type in "threadtest1" and press enter.
    - TO run the second test, type in "threadtest2" and press enter.
2. For part 2:
    - To run the first test, type in "mutextest1" and press enter.
    - To run the second test, type in "mutextest2" and press enter.
